Offline CV copy maker

Use this only if you open the portfolio by double-clicking index.html. In that mode browsers block normal downloads, so the site uses a saved copy of your CV from offline-files.js. On GitHub Pages or Live Server you don’t need this.

  1. Choose your latest CV.
  2. Click Create offline-files.js.
  3. Upload the downloaded offline-files.js to GitHub, replacing the old one.
